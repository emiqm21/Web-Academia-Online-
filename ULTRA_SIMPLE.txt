📋 SOLO 3 PASOS (5 MINUTOS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASO 1: Crear Repo en GitHub
─────────────────────────────
1. Ve a github.com/new
2. Nombre: academia-online-pro
3. Click "Create Repository"
4. LISTO ✓


PASO 2: Conectar tu Carpeta con GitHub
───────────────────────────────────────
En PowerShell, copia y pega (UNA VEZ):

git remote add origin https://github.com/TU_USERNAME/academia-online-pro.git
git branch -M main
git push -u origin main

(Reemplaza TU_USERNAME con tu usuario de GitHub)

LISTO ✓


PASO 3: Conectar GitHub ↔ Shopify
─────────────────────────────────
En Shopify Admin:
1. Online Store → Themes
2. Click en tu tema
3. Settings → Conectar GitHub
4. Selecciona tu repositorio
5. LISTO ✓

(Si no lo ves, Google "Shopify GitHub integration")


✨ AHORA FUNCIONA AUTOMÁTICAMENTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Flujo Diario:

1. Abres VSCode
2. Editas cualquier archivo
   (hero-premium.liquid, quiz-premium.liquid, etc)
3. Presionas Ctrl+S
4. En PowerShell escribes:
   git add -A
   git commit -m "🎨 Cambios"
   git push origin main
5. ¡TU TIENDA SE ACTUALIZA AUTOMÁTICAMENTE EN SHOPIFY!
